# Coverage expansion extraction contract, version 0.2.0

Apply README.md and research/EXTRACTION_CONTRACT.md with the following additive instructions. Original 0.1 inputs and release outputs must not be edited. Work only in your assigned new research directory. Reuse relevant existing snapshots read-only when useful; source IDs must not collide with the old corpus.

The task is to fill missing priority cytokine evidence with primary human studies, not just resource-level annotations. For every assigned cytokine aim for one directly observed target response and, when accessible, receptor-dependent response or an actual source-cell secretion observation. Capture genomic/transcriptional/proteomic bridges only when specifically supported; no completion quotas or invented biology. A carefully logged unresolved item is preferable to a fabricated edge.

Use the original pack JSON structure, with your new prefix for all assertion/source/cohort/search IDs. Include 2–4 narrow assertions per entity where supported. Evidence summaries should be concise paraphrases. Every assertion must have a saved accessible source, precise source locator, explicit cell/context, assay, limitations and evidence grade. Prefer accessible full text over snippets; abstract-only records need full-text review unless the entire claim is directly and narrowly supported and reviewed. Search and preserve null/context-contrast results. Canonical cytokine proteins use their gene symbol as the entity name, type=protein, layer=P; RNA targets are type=transcript, layer=T. Source-cell entities use layer=C. Molecular species/isoforms remain distinct where required.

The additional measurement `binding` is allowed for directly measured biochemical ligand/receptor binding (object layer P). Do not relabel binding as signaling or receptor abundance as functional availability. IL12A:IL12B is the IL-12p70 biological complex only when source identity is established; do not resolve the user's unspecific IL-12 assay. VEGFA is a biological protein only; the unspecific VEGF assay stays unresolved pending platform documentation.

Retain all required context fields as unavailable when not reported. For numerical effects add optional `quantitative_result` with reported value, unit, comparator, uncertainty, donor/sample basis and locator only if genuinely available. This is an observed result, not a calibrated prior. Do not invent confidence intervals from plots or transform P-values into probabilities of truth.

Add per-assertion `scoring_annotation` containing `tested_hypothesis` (canonical narrow proposition independent of raw observed sign), `evidence_relation` (supports/opposes/inconclusive), `null_adequacy`, and `rationale`. All ordinary nonsignificant or thresholded nulls are inconclusive for absence unless equivalence/precision evidence is supplied. A null observation remains searchable; it cannot update an existence prior merely because its predicate is phrased negatively.

Save exact real searches and all screened candidate citations in `screening.json`: candidate_id, query_id, title, url, DOI/PMID if known, decision (include/exclude/await_full_text), and specific reason. Do not imply a query's ranked search results are an exhaustive systematic corpus. Record citation chaining when actually performed and distinguish reuses of one study from independent biology.

Deliver pack.json, notes.md, run.json, screening.json, and supporting source snapshots. Record actual runtime timestamps and unknown model/reasoning metadata honestly. Original skill transport helpers should be used where applicable; documented public browser/HTTP fallbacks are permissible when those helpers cannot retrieve the source. No human adjudication or empirical probability calibration is claimed. The coordinating agent will arrange independent cross-review and versioned integration.
