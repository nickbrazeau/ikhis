# All-cytokine discovery inventory

The fixed cytokine priority set has been removed. The dated seed inventory combines complete UniProt stream responses for human entries annotated with the Cytokine keyword (KW-0202) or cytokine activity (GO:0005125), retaining both reviewed and unreviewed resource entries in separate states. The initial 10-record search was only an endpoint probe; the inventory uses the subsequent full stream responses.

UniProt's keyword definition includes chemokines and several cytokine families, and its broad annotation set also includes proteins with overlapping functions. Consequently, this is a source-annotated discovery registry, not a definitive count of active cytokine molecules. An accession is not an independent study, and an entry or subunit is not automatically an active cytokine complex. All cytokines remain eligible beyond the resource's current annotations.

The inventory creates no biological assertions or numerical priors. Source-cell, receptor, transcriptional, protein and functional evidence must be extracted separately. Historic assay-channel labels have no role in inclusion or completion metrics.

Definition source: [UniProt Cytokine keyword](https://www.uniprot.org/keywords/KW-0202). Exact queries, saved results, response status and snapshot hashes are in inventory_manifest.json. No numeric resource release was inferred from an unrelated page; the helper's response did not preserve version headers.
