# Protocol amendment 0.3.0 — all-cytokine scope and mechanism candidates

The user requested steps 1–3 followed by a separately triggered review, and explicitly removed the fixed cytokine priority coverage set. This amendment supersedes priority-panel language in earlier operational documents for current work. Frozen earlier releases retain their original scope and evidence as history.

All cytokines and the broader genomic, transcriptional, proteomic, signaling and cellular-function domains are eligible. The active product scope and acceptance criteria are in PRODUCT_SCOPE.md. A resource-derived cytokine inventory is a discovery registry, not a set of extracted causal assertions.

New mechanism evidence is staged beside the verified 0.2.0 baseline. It must use explicit pending-review states. The candidate builder cannot modify baseline priors or create an approved materialized pathway. It distinguishes serial transitions, mediation tests, shared-intervention branches and context contrasts. A bridge requires its own source locators, biological and measurement compatibility, temporal rationale and experimental linkage; matching entity labels alone are insufficient.

Independent review is intentionally not run in this phase. Structural tests and source-dependency checks prepare a reviewable artifact without supplying biological adjudication. No production freeze or probability calibration is authorized as part of these three steps.
