Additional and detailed Methods:  Analysis of RNA-seq data RNA-seq sequencing and differential expression analysis Raw fastq files were aligned to the human genome (GRCh38; GenBank assembly GCA_000001405.40) using the STAR1 pipeline (v2.7.10b). HTSeq-count2 (v2.0.2) was used to generate gene counts and genes were filtered to retain those with raw read counts ≥ 10 in at least 2 samples. The resulting gene expression matrix was subsequently normalized using the trimmed mean of M value (TMM) method.   Genes with low read counts were removed and DEG analysis was performed using the DESeq23 (v1.42.1) package while accounting for covariates such as donor effects. The resulting p-values were adjusted for multiple hypothesis testing and filtered to retain DEGs with a q-value < 0.05.  For GSEA analysis (Fig. 3f), we used the LFC values obtained from DESeq2 as input for enrichment with the fgsea (v1.26.0)4 package. Annotated positive or negative DEGs were derived from comparisons between in vitro expanded nTreg and Tconvs and were used as the reference gene annotation database. Processing and visualization of genomic data Initial quality-control assessment was performed using the FastQC toolkit (v0.11.8; https://github.com/s-andrews/FastQC). For ATAC-seq and inATAC-seq, raw fastq files were first trimmed using Trim Galore (v0.6.4)5 to remove contaminating Illumina adapter sequences. Fastq files were aligned to the human genome (GRCh38; GenBank assembly GCA_000001405.40) using bowtie2 (v2.5.0)6 and processed with samtools (v1.17)7. Genomic tracks for ChIP-seq, ATAC-seq, inChIP-seq and inATAC-seq data were generated using the deepTools (v2.0)8 bamCoverage function and visualized on the WashU Epigenome Browser9. Peaks were called using macs2 (v2.2.9.1)10. CUT&RUN data was processed using the CUT&RUNTools (v2.0) pipeline11, following recommended settings.  Analysis of Perturb-Seq data Preprocessing For the scRNA data, sequencing reads for all libraries were aligned to the hg38 reference genomes using cellranger (v7.0.0). Surface protein tag abundances and CROP-seq gRNA reads were estimated using the kallisto (v0.44.0), bustools (v0.39.3) and kite (v0.02) frameworks12,13. Intracellular protein tag abundances were estimated using cellranger (v7.0.0).  Data processing Data were analyzed using Seurat 4.1.214. Low-quality cells were filtered based on standard quality-control metrics. In particular, cells were filtered based on mitochondrial content (allowing for a maximum of 5%), complexity (total RNA UMIs less than 3,000 or more than 50,000) and by the

number of detected genes (removing cells expressing less than 1,000 detected genes). Mitochondrial and ribosomal genes were excluded from subsequent analyses. RNA counts were normalized by total counts and log-transformed.  From the hashtag count matrix, we assigned donor identity using the HTOdemux() function from Seurat (with quantile = 0.90) Cells with less than 50 total UMI counts from intracellular protein staining were discarded. All Protein assays were normalized with the centered log-ratio (CLR) method.  Guide RNAs were assigned by the following method15: gRNA identities with an UMI count greater than 4*SD (4*standard deviation) were assigned to each cell. Cells resulting with more than one assigned gRNA were considered as multiplets, while cells with less than 10 UMI counts were considered negative.   Regulatory coefficient inference We used the MIMOSCA16 and Perturb-CITE-seq17 frameworks to infer the regulatory effect of each gRNA on the transcriptome. Briefly, this analysis includes two major iterative steps. The first step is a linear regression (LR), via an elastic net regularization, which generates a regulatory coefficient matrix. In addition to gRNA assignment, the LR accounts for both technical and biological variations through the evaluation of confounding factors, namely the total number of UMI counts mitochondrial content, donor batch and cell cycle phase (previously calculated with CellCycleScoring() from Seurat). The second step inferences the probability of perturbation for each cell through an expectation maximization (EM)-like procedure.    The first LR was performed on 3,074 features, selected in accordance with a previous study18. A relative z-normalization towards the non-target cells (NTC) was applied to each library. Then, an Anderson-Darling test was performed (with the kSamples v1.2 R package) for each gRNA, and asymptotic p-values were corrected with Benjamini-Hochberg (BH) method (with the multtest v3.20 R package19). The union across all the different gRNAs of the respective top 10 genes with an adjusted p-value less than 0.1 was finally selected for LR.  Following the first LR, perturbation probabilities were inferred, and the obtained covariate matrix was submitted for a second LR. At this step, a correlation matrix towards gRNAs was computed on the regulatory coefficient matrix. Correlations of gRNAs targeting different genes were used to build a null distribution and ultimately calculate the empirical cumulative distribution function and empirical p-values for each pair of gRNAs targeting the same gene. All the gRNAs belonging to at least one gRNA pair with a BH adjusted p-value less than 0.05 were kept for the next LR, which performed on the 228 selected targets (KOs). As previously, perturbation probabilities were calculated once again, leading to a final LR step. For further analyses, only cells with a perturbation

Module definition Targets displaying only null coefficients were discarded. Additionally, genes with less than 4 absolute coefficients greater than 0.08 were discarded as well. Both target and gene modules were defined based on kmeans clustering (k = 20, 500 initializations). Clusters with similar coefficient profiles were merged, defining in total 11 and 10 target and gene clusters, respectively. UMAP coordinates were calculated with umap. Graphs and centrality measures were generated and calculated with igraph 1.4.2.
